# Documentation

Planning documents are kept in the backend repository `oms-be` under `docs/` so there is one source of truth:

- `PRODUCT_REQUIREMENTS.markdown`
- `ARCHITECTURE.markdown` (see §12 for the portal architecture)
- `API_CONVENTIONS.markdown`
- `DECISIONS.markdown`
- `IMPLEMENTATION_PLAN.markdown`

Portal-specific documents (component conventions, theming, i18n catalog rules) will be added here as the portal grows. For now the conventions are in the root `README.markdown`.
