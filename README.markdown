# oms-portal

Merchant portal (frontend) for the OMS platform. Companion of `oms-be`.

**Status:** planning (Stage 6). No application code yet.

Stack (approved): Next.js 16 · React 19 · strict TypeScript 6.0 · Node 24 LTS · Material UI (centralized theme) · RTK Query + axios · OpenAPI-generated types · react-hook-form + zod · next-intl (Spanish-only MVP) · pnpm · Vitest + Testing Library.

Project documentation lives in the backend repo (`oms-be/docs/`) as the single source of truth. See [docs/README.markdown](docs/README.markdown).
